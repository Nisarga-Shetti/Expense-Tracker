# Expense Tracker

A simple and responsive Expense Tracker built using HTML, CSS, and JavaScript. Track income, expenses, and available balance.

## Features

- Add income and expenses.
- Calculate total income automatically.
- Calculate total expenses automatically.
- Display available balance.
- View transaction history.
- Delete transactions.
- Save transactions using Local Storage.
- Responsive design.
- Indian Rupee (₹) currency format.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

1. Download or clone this repository.

3. Open `index.html` in your browser or use Live Server.
